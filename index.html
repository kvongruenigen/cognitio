01 / The battery

Different tasks.
A broader perspective.

Choose a task for the cognitive function you want to explore. Configure its settings before starting a session.

01

Attention & speed

Psychomotor Vigilance Test PVT

Explore sustained attention by responding as quickly as possible when a visual stimulus appears after an unpredictable delay. The task records reaction times, lapses, and false starts, showing how response speed and consistency vary during the session.

Stroop Test STROOP

Identify the ink color of a word while ignoring what the word says. Some trials match the word to its color; others create a conflict, such as the word GREEN displayed in red. Reaction time and accuracy capture how participants handle this interference.

Flanker Test FLANKER

Respond to the direction of the center arrow while ignoring the arrows on either side. The surrounding arrows can point in the same or opposite direction, creating different levels of distraction. The task records response speed and accuracy to explore selective attention and conflict resolution.

02

Memory

N-Back Test N-BACK

Follow a stream of letters and respond when the current letter matches the one shown a specified number of trials earlier. Keeping track requires continuously updating the information held in working memory. The task records correct matches, missed matches, false alarms, and reaction times.

Digit Span Test DIGIT SPAN

Watch a sequence of digits, then enter them in the same order from memory. Longer sequences increase the amount of information that must be retained and reproduced. The task records sequence length, the recalled digits, and accuracy to explore verbal memory span.

Corsi Span Test CORSI

Watch blocks light up in sequence, then click them in the same order. The sequence grows after correct responses, increasing the demand on visuospatial memory. The task records the shown and recalled sequences, span length, and errors.

03

Control & flexibility

Go/No-Go Test GO / NO-GO

Respond when GO appears and withhold your response when NO-GO appears. Repeated go trials build a tendency to respond, making it harder to stop on a no-go trial. Reaction times and response errors capture attention and the ability to inhibit an automatic response.

Stop Signal Task STOP SIGNAL

Respond quickly to a directional arrow, but withhold your response if a stop signal appears shortly afterward. Because the signal arrives after the initial stimulus, participants may already be preparing to act. The task records stop-signal delays, reaction times, and response outcomes to explore response cancellation.

Task Switching Test SWITCHING

Classify a letter as a vowel or consonant, or a number as odd or even, depending on where the letter–number pair appears on screen. The task includes letter, number, and mixed blocks. Response speed and accuracy on repeat and switch trials help describe the effort involved in changing task rules.

Task Switching Cued Test CUED

Use the cue shown before each stimulus to decide whether to respond to its shape or its color. Participants alternate between identifying circles or rectangles and identifying orange or blue. The task records reaction times and accuracy on repeat and switch trials to explore how advance cues guide changes in attention.

Select a task above to learn more. Try all ten in Cognitio Light for anonymous browser sessions and CSV downloads, or use the desktop app for participant records and reports.

Where can I find instructions for the app?

Open Help in the desktop app for the User Guide and Test Descriptions. Start by selecting a participant, then choose a task from the Tests screen.

Can I run the tests on this website?

Yes. Open Cognitio Light to run all ten tasks using touch controls or a keyboard. Review results immediately and download session trials as CSV. Sessions stay in the page’s memory and disappear when you reload or close it; no participant records are created. The desktop app adds saved participant records, session history, and PDF reports.
