01 / The battery

Different tasks.
A broader perspective.

Choose a task for the cognitive function you want to explore. Configure its settings before starting a session.

01

Attention & speed

Psychomotor Vigilance Test PVT

Measures sustained attention and reaction speed over time.

Stroop Test STROOP

Assesses interference control and executive attention.

Flanker Test FLANKER

Assesses selective attention and conflict resolution.

02

Memory

N-Back Test N-BACK

Measures online updating in working memory.

Digit Span Test DIGIT SPAN

Evaluates verbal working-memory span capacity.

Corsi Span Test CORSI

Assesses visuospatial short-term memory span.

03

Control & flexibility

Go/No-Go Test GO / NO-GO

Assesses response inhibition and impulse control.

Stop Signal Task STOP SIGNAL

Measures the ability to cancel an initiated response.

Task Switching Test SWITCHING

Evaluates cognitive flexibility between task rules.

Task Switching Cued Test CUED

Measures cue-driven reconfiguration of task sets.

Select a task above to learn more. These tasks run in the desktop app.

02 / Your workflow

From participant
to perspective.

Keep participant management, task configuration, and results in the same desktop workspace.

  1. 01

    Select a participant

    Register a new participant or select an existing record to begin.

  2. 02

    Set up the session

    Choose a task and adjust its available parameters in Settings.

  3. 03

    Run the task

    Complete the task while the app records session and trial data locally.

  4. 04

    Review & export

    Inspect session summaries and trial details. Export CSV data or a participant PDF report.

⌘

Your workspace. Your local data.

Participant records, sessions, and trials are stored in a local SQLite database. Export results when you’re ready to work with them elsewhere.
